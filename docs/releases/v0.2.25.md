XyMusic v0.2.25 预发布构建。

新增
1. 桌面端设置页按设计稿重构：顶部标签加独立滚动区，新增常规、界面、语言、自定义资源、关于标签页，原界面、语言、自定义 API、代理、播放音质、缓存上限、存储管理等独立设置页内容迁移进设置页
2. 桌面端艺术家详情页与专辑详情页按设计稿重做：概览读数条、章节导航与下划线标签，歌曲列表支持批量选择
3. 抽取通用选择组件（选择开关按钮、选择操作栏动画），音乐列表、艺术家与专辑详情、收藏页、本地与下载页统一使用；桌面端本地歌曲支持批量选择删除，收藏页新增批量选择
4. 新增通用紧凑开关 XySwitch、统一页面头部 JvmPageHeader、通用下划线标签等跨端组件
5. 支持自定义音乐下载目录，目录不可用时回落平台默认目录
6. 桌面端本地与下载页面新增「打开文件所在位置」入口
7. 桌面端右键菜单重做：统一歌词偏移菜单结构，支持可拖拽滚动条
8. 桌面端新增媒体库切换页，点击库行即可切换当前可见媒体库范围，选择列表支持宽窗口双列布局

更新
1. 桌面端侧边栏改为单列分组导航并带滚动条，歌曲搜索框移至侧边栏顶部，播放栏改为只占右侧内容区
2. 桌面端顶部栏改为品牌面包屑布局，返回按钮位置固定
3. 歌曲表格列宽策略调整：标题列按最长歌名测量，专辑列吸收剩余空间并限制最大宽度，操作列居中，专辑名被截断时悬停显示完整名称
4. 拆分移动端与桌面端配色并收敛硬编码颜色，统一按钮、菜单、歌单与设置项的悬停变色
5. 重构通用弹窗组件，用语义色统一驱动外观，危险操作补充取消按钮，弹窗图标与引导文案迁入字符串资源
6. 桌面端歌曲列表显示已下载状态并禁止重复下载
7. 桌面端歌单列表项补全封面占位图并统一内边距
8. 升级 Android Gradle 插件版本
9. 调整 KMP 单元测试工作流触发条件，仅在推送 tag 时自动执行
10. 更新应用版本号至 0.2.25，Android versionCode 更新为 7

修复
1. 修复批量播放选中后播放队列顺序错乱
2. 修复桌面端音乐页退出选择模式后标题被顶出视口
3. 修复桌面端播放栏左侧封面被压缩导致底部裁切
4. 修复首页歌曲下载后无法播放
5. 修复清空数据库后重新登录不刷新数据
6. 登录失败提示支持手动关闭，关闭后不再阻塞本地缓存浏览
7. 修复桌面端首页专辑网格与分区标题缺失左右间距
8. 提高背景图遮罩不透明度，修复内容区文字对比度不足

构建产物
1. Android release APK：XyMusic-0.2.25-7-release.apk
2. Android release AAB：XyMusic-0.2.25-7-release.aab
3. Windows release MSI：XyMusic-0.2.25-windows-x64.msi
4. SHA256SUMS-android.txt 和 SHA256SUMS-windows.txt 校验文件

## What's Changed
- 桌面端设置页、艺术家与专辑详情页按设计稿重构，原独立设置子页迁移进设置页标签
- 桌面端批量选择统一为通用选择组件，本地歌曲支持批量删除，收藏页新增批量选择
- 桌面端侧边栏、顶部栏、右键菜单与媒体库页面重构
- 支持自定义音乐下载目录
- 修复批量播放队列顺序错乱、选择态标题被顶出视口等问题
- 更新版本号至 0.2.25，Android versionCode 更新为 7
