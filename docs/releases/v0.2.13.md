XyMusic v0.2.13 正式构建。

新增

1. 桌面端「连接到媒体服务器」页面按设计稿重做：协议选择轨、凭据表单与结果卡，协议列表展示官方图标与最低支持版本
2. 桌面端连接页首次打开时，标题栏新增主题模式切换按钮
3. 桌面端系统托盘支持播放/暂停、上一曲、下一曲
4. 桌面端窗口标题跟随播放状态：播放中显示「正在播放 - 歌曲名」，暂停时显示「已暂停 - 应用名称」
5. 桌面端设置页支持自定义歌曲缓存目录与下载目录，切换目录时可迁移旧缓存

更新

1. 桌面端托盘右键菜单改用 Win32 原生菜单，解决中文显示为方块的问题；菜单在独立线程跟踪，避免阻塞界面
2. 托盘图标与窗口/任务栏图标统一使用应用 logo
3. 精简连接页交互与状态展示：移除重新选择、错误态修改连接信息与用户名清除按钮，底部状态条只保留状态与地址
4. 重构 JVM 数据目录，统一下载临时文件目录
5. 统一缓存目录命名与图片缓存路径，Android 端音乐缓存目录调整到应用私有外部存储
6. 容量格式化工具下沉到 xy-platform 共享模块
7. 桌面端播放时跳过相似歌曲与歌手热门歌曲推荐请求，减少无效请求
8. 调整连接与登录失败提示配色，补全登录异常详细错误信息
9. createHttpClient 日志改为 info 级别，并打印实际创建的子类全名
10. 修正 Plex 最低支持版本与版本校验字段
11. 发布工作流改为推送 v* 标签时自动触发，预发布默认为 true
12. 更新应用版本号至 0.2.13，Android versionCode 更新为 7

修复

1. 修复桌面端 MSI 安装后启动报 Failed to launch JVM：为 Room 补充 ProGuard 保留规则，避免数据库实现类被混淆
2. 修复托盘右键菜单只能弹出一次
3. 修复托盘右键时任务栏出现多余窗口按钮
4. 修复 JVM 首页数据乱序加载导致滚动位置停在中间分区
5. 修复首次连接选错数据源类型后切换正确类型导致 httpClient 未初始化，切换数据源时关闭旧服务避免连接池泄漏
6. 修复 Subsonic 业务失败被静默忽略，错误码 40 抛出未授权异常
7. 修复接口异常处理日志为空，补充请求地址、状态码与响应体日志
8. 移除 PlexDatasourceServer 中多余的 toString 转换

构建产物

1. Android release APK：XyMusic-0.2.13-7-release.apk
2. Android release AAB：XyMusic-0.2.13-7-release.aab
3. Windows release MSI：XyMusic-0.2.13-windows-x64.msi
4. SHA256SUMS-android.txt 和 SHA256SUMS-windows.txt 校验文件

## What's Changed
- 桌面端连接到媒体服务器页面按设计稿重做，新增主题模式切换与更完整的登录错误提示
- 桌面端系统托盘重做：Win32 原生右键菜单，支持播放控制，修复菜单只弹一次与中文乱码
- 桌面端支持自定义歌曲缓存与下载目录，切换时可迁移旧缓存
- JVM 数据目录与下载临时目录统一，Android 端缓存目录调整到应用私有外部存储
- 修复桌面端 MSI 启动失败、首页滚动错位、首次连接客户端未初始化等问题
- 更新版本号至 0.2.13，Android versionCode 更新为 7
