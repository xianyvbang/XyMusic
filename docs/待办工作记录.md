## 2. 登录失败弹窗可关闭

**目标**：登录失败时弹出的提示弹窗支持用户主动关闭，不再强制阻塞操作。

**要点**：

- 弹窗增加关闭按钮（或点击遮罩/返回键关闭）。
- 关闭后不重复弹出，用户可继续浏览本地缓存内容。
- 保留重试入口，关闭弹窗不影响后续手动重新登录。
- 校验：登录失败 → 弹窗出现 → 点击关闭 → 弹窗消失且页面可正常操作。

## 5. 支持修改音乐下载目录

**目标**：在设置页面中支持自定义歌曲下载文件的保存目录，替代当前只能使用平台默认下载目录的限制。

**现状**：

- 下载目录目前由 `DownloadPlatformFiles.defaultDownloadDirectory` 解析后写入 `DownloaderConfig.finalDirectory`，用户无法修改。
- 设置页中的「歌曲缓存位置」只展示 `downloaderManager.config.finalDirectory`，点击仅复制路径，没有选择目录的入口。
- 已有可参考的实现：播放缓存目录（`cacheFilePath`）已支持通过系统目录选择器切换并持久化，下载目录可复用同样的交互与持久化方式。

**要点**：

- 在设置页「歌曲缓存位置」处增加「修改下载目录」入口，点击后调用平台目录选择器（Android 使用 SAF 目录授权，JVM 使用 FileKit 目录选择器）选择目标目录。
- 将选择的目录持久化到设置表（新增字段，保持默认值为空表示使用平台默认目录），下载管理器初始化时用该值覆盖 `DownloaderConfig.finalDirectory`，重启后生效。
- 提供「恢复默认目录」操作，清空自定义路径后回落到平台默认下载目录。
- 切换目录时给出明确策略：已下载文件不做自动搬运（保持原路径可播放），或提供迁移选项并在迁移时校验 MD5；需保证下载任务记录中的 `filePath` 与实际文件位置一致，避免播放/清理时找不到文件。
- 目录不可用（无写权限、磁盘空间不足、路径被删除）时给出提示并回退到默认目录，不阻塞下载功能。
- 校验：设置中修改下载目录 → 新建下载任务的文件落在新目录 → 重启应用后仍指向新目录 → 恢复默认后回到平台默认下载目录；无权限目录被拒绝并提示。

## 6. 存储占用进度条改为项目主题渐变配色

**目标**：设置页存储管理分区的占用进度条由当前的多分类色块拼接，改为参考截图中「同色系由亮到暗渐变、分段之间无明显色相跳变」的样式，但配色必须取自项目主题色，去除截图中偏橙粉的观感。

**现状**：

- 进度条由 `JvmStorageStackedBar` 绘制，每个分类直接使用自己的 `item.color`，四段颜色分别是 primary / tertiary / error / secondary，色相差异大，视觉上比较杂乱且包含偏粉的色感。
- 图例圆点（`JvmStorageLegendItem`）复用同一份 `item.color`，因此调整进度条时必须同步调整图例，否则两者对不上。

**要点**：

- 进度条整体改用单一主题色系的线性渐变：从主题亮色（如 `primary` / `primaryContainer`）过渡到同一色相的深色（如 `onPrimaryContainer` 或 `primary` 降低明度/透明度），不引入粉色、红橙等偏离主题的色相。
- 每段按照其在总占用中的位置，从整条渐变的对应区间取样（用 `Brush` + 偏移裁剪或等价的 `drawWithCache` 方案），保证相邻两段之间是同色相的连续过渡，只保留极细的间隙或完全不保留间隙。
- 各段之间仍要能区分，可通过明度差、透明度衰减或 1px 分隔实现，不再依赖不同色相。
- 图例圆点颜色改为取各段在渐变中的实际颜色，保持与进度条一一对应；如需保留少量颜色区分，也只能在同一色系内做明度变化。
- 背景轨道沿用当前的 `onSurface.copy(alpha = 0.08f)`，圆角与高度保持不变，深色/浅色主题下都要校验对比度与可读性。
- 校验：浅色与深色主题下进度条呈现连续渐变、无粉色块；图例颜色与进度条对应；某一分类为 0 时不出现空段或错位。

**要点**：

- 将图例文字字号提升一档到 `bodySmall`（或直接指定更大的 `fontSize`），颜色仍使用 `onSurfaceVariant`。

- 文字放大后需保证多个图例在窄窗口下正常换行、不溢出、不与进度条或分类行重叠，行间距保持合理。
- 只调整图例文字与圆点，进度条高度、圆角与颜色方案保持不变。
- 校验：设置页存储管理分区中图例文字明显大于原来且清晰可读；窗口缩放时图例自动换行不错位。
