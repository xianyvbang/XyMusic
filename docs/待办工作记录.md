## 7. 加大存储管理进度条下方图例文字字号

**目标**：放大存储管理进度条下方「颜色圆点 + 分类名称 + 容量」图例文字的字号，提升可读性。

**现状**：

- 图例文字由 `JvmStorageLegendItem` 使用 `MaterialTheme.typography.labelSmall` 渲染，字号偏小，在进度条下方的信息辨识度不足。

**要点**：

- 将图例文字字号提升一档到 `bodySmall`（或直接指定更大的 `fontSize`），颜色仍使用 `onSurfaceVariant`。
- 图例圆点尺寸（当前 7dp）同步适度放大，保持与文字视觉比例协调。
- 文字放大后需保证多个图例在窄窗口下正常换行、不溢出、不与进度条或分类行重叠，行间距保持合理。
- 只调整图例文字与圆点，进度条高度、圆角与颜色方案保持不变。
- 校验：设置页存储管理分区中图例文字明显大于原来且清晰可读；窗口缩放时图例自动换行不错位。

## 8. JVM 端设置页面写死的 sp/dp 统一迁移到 XyTheme.dimens

**目标**：把 jvm 端设置相关页面里写死的 `xx.dp` / `xx.sp` 换成 `XyTheme.dimens` 中的统一维度；`XyDimens` 里没有对应项、但在多个页面重复出现的，抽取成通用维度字段；只属于单个页面布局策略（断点、卡片宽度等）的，抽成该页面的命名常量，不再散落魔法数字。

**现状**：

- 现有 `XyDimens` 只有 9 个字段：`corner`(12)、`dialogCorner`(20)、`outerHorizontalPadding`(16)、`innerHorizontalPadding`(16)、`outerVerticalPadding`(8)、`innerVerticalPadding`(12)、`contentPadding`(12)、`snackBarPlayerHeight`（平台差异，JVM 76）、`itemHeight`(62)。

- 高频取值分布（设置相关文件合计）：`1.dp` 94 处、`2.dp` 15 处、`14.dp` 11 处、`0.dp` 10 处、`4.dp` 8 处、`3.dp` 7 处、`18.dp` 7 处、`7.dp` 7 处、`8/12/20/32/38.dp` 各 5 处。
- sp 侧几乎都是 `MaterialTheme.typography.xxx.copy(fontSize = ..., lineHeight = ...)` 的临时改写，如 `13.sp`×3、`11.5.sp`×3、`16.sp`×3、`20.sp`×3、`9.5.sp`×2。

**要点**：

- 第一类：能直接换成现有 `XyDimens` 字段的（1:1 平移，不改像素值）。
  - 页面/卡片内边距、列表间距：`padding`、`spacedBy` 中的 8/12/16 dp → `outerVerticalPadding`、`contentPadding`、`outerHorizontalPadding`，需要半档时用 `/ 2`、`* 2` 派生（与现有写法一致）。
  - 圆角：`RoundedCornerShape(12.dp)` → `XyTheme.dimens.corner`；`20.dp` → `XyTheme.dimens.dialogCorner`。
  - 设置行最小行高：`minHeight = 62.dp / 64.dp / 72.dp` 的设置行统一走 `itemHeight`（视觉差异明显的行，如多行路径行，用 `itemHeight + outerVerticalPadding` 之类派生表达，不要直接写 72.dp）。
- 第二类：抽取成 `XyDimens` 新字段（多处重复、属于全局设计节奏）。
  - `strokeWidth = 1.dp`：当前 `BorderStroke(1.dp)` / `width = 1.dp` / `height(1.dp)` 合计约 50 处，是最高频硬编码，优先抽取。
  - `iconSizeSmall = 14.dp`、`iconSize = 18.dp`、`iconSizeMedium = 20.dp`、`iconSizeLarge = 24.dp`、`iconContainerSize = 30.dp`、`avatarSize = 56.dp`。
  - `controlHeightSmall = 26.dp`、`controlHeight = 32.dp`、`controlHeightMedium = 38.dp`、`controlHeightLarge = 44.dp`（按钮、输入框、工具栏统一用档位表达）。
  - `tagCorner = 4.dp`、`tagCornerSmall = 2.dp`、`pillCorner = 7.dp`（标签、胶囊、悬停高亮行统一圆角）。
  - `gapTiny = 2.dp`、`gapSmall = 4.dp`、`gap = 8.dp`（子元素间距档位，替代大量 2/4/8 dp）。
- 第三类：sp / 排版，单独抽 `XyTypography`（或 `XyTextStyles`）而不是塞进 `XyDimens`。
  - 把 `copy(fontSize = 13.sp, lineHeight = 16.sp)` 这类重复改写归纳为：设置项标题、设置项次级描述、设置项小标签（等宽大写小字）、页面大标题、页面说明文案、读数元信息等固定样式。
  - 迁移后页面里只引用样式对象，不再逐个 `.copy(fontSize = ...)`；`letterSpacing` 的 0.9/1.0/1.2 sp 也一并收进样式。
  - 注意待办第 7 项（存储图例字号）会改动图例文字字号，样式抽取时把图例字号作为参数保留，避免和第 7 项冲突。
- 第四类：不能代替、只服务于单页布局策略的，保留为页面内命名常量并统一命名（如 `XxxBreakpoint`、`XxxMinWidth`、`XxxPreviewHeight`）。
  - 断点：`860.dp`（两栏）、`760.dp`（三列概览）、`640.dp`（双列）、`620.dp`、`560.dp`（背景预览紧凑）——断点属于布局决策，不放入 `XyDimens`，但同一断点在多页面复用时抽到共用常量。
  - 概览/摘要卡尺寸：`284.dp`、`240.dp`、`220.dp`、`196.dp`、`154.dp`、`152.dp`、`140.dp`、`128.dp`、`112.dp`、`96.dp` 等卡片宽度与高度，归入页面常量，避免和全局间距体系混在一起。
  - 背景预览模拟尺寸（`58.dp` 播放条、`44.dp` 顶栏、`124.dp` 侧栏）、表头列宽（`420/300/120/112.dp`）等纯业务布局值，保持页面私有。
- 约束：
  - `XyDimens` 新字段必须带默认值，默认值等于当前实际像素，保证 Android / iOS 现有视觉完全不变；类内字段沿用 `mutableStateOf(..., structuralEqualityPolicy())` 写法。
  - 先做 1:1 平移，不做"顺便调优"；统一视觉比例另开需求。
  - 新增字段、方法、属性补中文注释（项目规则）。
- 校验：编译通过；设置页四个标签、连接、代理、语言、界面、关于、存储、缓存上限、内存管理、下载等页面迁移前后视觉逐像素一致（截图对比）；深色/浅色切换、窗口缩放跨断点行为不变；`grep` 确认这些文件中不再存在可被维度体系覆盖的字面值。
